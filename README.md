## 🚀 Main Projects

### STM32 기반 통신 및 제어

STM32 마이크로컨트롤러를 활용한 외부 장치 데이터 통신 및 구동 장치 제어 프로젝트

**주요 내용**

- UART 기반 장치 간 데이터 통신
- 센서 입력 데이터 수신 및 처리
- DC 모터 및 스텝 모터 구동
- 모터 드라이버와 STM32 연결
- 컨베이어 및 구동 장치 제어
- PC와 STM32 간 명령 및 상태 데이터 송수신

<br>

### [WorkProof](https://github.com/dohyeon16/WorkProof)

근무 기록과 실제 급여를 비교하고 관련 증빙 자료를 관리할 수 있도록 개발한 React Native 기반 모바일 애플리케이션 프로젝트

**주요 기능**

- 소셜 로그인
- 근무지 정보 등록
- 출퇴근 시간 기록
- 예상 급여 계산
- 예상 급여와 실제 입금액 비교
- 근로계약서 및 증빙 자료 관리
- PDF 리포트 저장 및 공유

[Repository →](https://github.com/dohyeon16/WorkProof)

<br>

### LLM 기반 음성 제어 자율주행 배송 로봇

음성 명령, 사용자 추종, 자율주행 및 문서 출력 기능을 수행하는 배송 로봇 프로젝트

**담당 업무**

- 배송 로봇 전체 하드웨어 구조 설계 및 제작
- 알루미늄 프로파일 기반 로봇 프레임 조립
- 엔코더형 DC 모터와 구동 바퀴 설치
- 하드웨어 간 간섭 여부 확인 및 구조 개선
- 로봇 주행 및 시스템 통합을 위한 하드웨어 환경 구성

> 해당 프로젝트에서 로봇 하드웨어 제작과 장치 구성 업무 담당
